# 사용자 분실물 찾기 추가 실험

2026-11-10에 합성 물품 100개가 들어 있는 별도 SQLite DB로 `development_v2`를 추가 검증했다. 검색 가능한 보관 물품은 90개였다. 테스트 코드가 사용자를 대신해 실제 백엔드 API로 자연어 검색과 답변을 제출했고, 단서 추출·유사 물품 검색·오답 생성에는 실제 Gemini `gemini-3.5-flash-lite`를 사용했다. 후보 수는 저장된 시도에서 확인했다.

[직전 실험](ownership_workflow_v2_100_20261110.md)은 7개 사례 중 3개에서 추가 질문에 답했다. 이번에는 사용자 입력, 질문 문장, 화면에 표시된 순서의 선택지, 고른 답, 후보 변화, 판정을 기록했다.

## 결과 요약

추가 사례 10개 모두 기대한 결과를 확인했다. 이 중 6개에서는 객관식 총 10문항에 답했고, 모든 문항의 선택지는 서로 다른 5개였다. 첫 실행에서는 4개 사례를 완료했다. 17번째 Gemini 요청에서 `429` 사용량 제한을 받아 중단한 뒤, 미완료 사례 6개를 별도 실행해 모두 완료했다. 두 실행의 실제 요청은 각각 17회와 13회였다.

| 사례 | 후보 수 | 질문 수 | 결과 |
| --- | --- | --- | --- |
| 수첩, 비공개 특징 모두 정답 | 1 → 1 | 2 | 소유 근거 확인 |
| 지갑, 같은 비공개 특징을 가진 후보 둘 | 5 → 2 | 2 | 판정 보류 |
| 지갑, 서로 다른 후보의 답을 하나씩 선택 | 5 → 5 | 2 | 판정 보류 |
| 필통, 다른 후보의 실제 장식과 문구 선택 | 5 → 4 | 2 | 판정 보류 |
| 우산, DB에 있는 공개 재질 선택 | 5 → 1 | 1 | 판정 보류 |
| 우산, Gemini가 만든 재질 선택 | 5 → 5 | 1 | 판정 보류 |
| 이어폰, DB에 브랜드 없음 | 1 → 1 | 0 | 판정 보류 |
| 보온병, 확인할 비공개 특징 없음 | 1 → 1 | 0 | 판정 보류 |
| 헬멧, 등록 물품이 모두 보관 조건 미충족 | 0 | 0 | 후보 없음 |
| 물품 단서 없이 입력 | 0 | 0 | 단서 더 필요 |

## 질문과 답변 기록

### 1. 수첩의 비공개 특징을 전부 맞힌 경우

입력은 “학생회관에서 잃어버린 수첩을 찾고 있어요.”였다.

| 실제 질문 | 표시된 5개 선택지 | 선택한 답 | 후보 수 |
| --- | --- | --- | --- |
| 물건에 있던 장식이나 구별되는 특징 중 기억나는 것을 골라 주세요. | 자수 패치 / 홀로그램 스티커 / 실리콘 팔찌 / 물방울 배지 / 아크릴 키링 | 물방울 배지 | 1 → 1 |
| 물건에 적힌 문구 중 기억나는 것을 골라 주세요. | KP / TV / QX / LM / ZR | QX | 1 → 1 |

두 비공개 특징이 모두 일치했고, 유일한 후보 `N01`의 결과는 **소유 근거 확인**(`supported`)이었다.

### 2. 같은 비공개 특징을 가진 지갑이 두 개 남은 경우

입력은 “잃어버린 지갑이 있는지 찾아주세요.”였다.

| 실제 질문 | 표시된 5개 선택지 | 선택한 답 | 후보 수 |
| --- | --- | --- | --- |
| 물건에 있던 장식이나 구별되는 특징 중 기억나는 것을 골라 주세요. | 갈색 고리 / 푸른색 점 / 황금색 별 / 은색 나뭇잎 / 붉은색 줄무늬 | 은색 나뭇잎 | 5 → 5 |
| 물건에 적힌 문구 중 기억나는 것을 골라 주세요. | CD / AB / GH / IJ / EF | AB | 5 → 2 |

첫 답변에서 어긋난 세 후보는 한 번의 오답만 있어 유지됐다. 같은 세 후보가 문구에서도 어긋나 제외됐다. 두 답이 모두 일치한 `W01`, `W02`가 남아 **판정 보류**(`insufficient_evidence`)였다.

### 3. 지갑의 답변이 서로 다른 후보와 일치한 경우

입력은 “지갑을 잃어버렸어요.”였다.

| 실제 질문 | 표시된 5개 선택지 | 선택한 답 | 후보 수 |
| --- | --- | --- | --- |
| 물건에 있던 장식이나 구별되는 특징 중 기억나는 것을 골라 주세요. | 갈색 고리 / 붉은색 줄무늬 / 황금색 별 / 푸른색 다이아몬드 / 은색 나뭇잎 | 은색 나뭇잎 | 5 → 5 |
| 물건에 적힌 문구 중 기억나는 것을 골라 주세요. | EF / AB / IJ / CD / GH | CD | 5 → 5 |

장식은 `W01`, `W02`와 일치했고, 문구는 `W03`~`W05`와 일치했다. 후보별로 하나씩만 맞고 하나씩 어긋나 다섯 개가 남았으며 **판정 보류**였다.

### 4. 앞선 실험과 다른 필통의 답을 선택한 경우

입력은 “도서관에서 필통을 찾고 있어요.”였다.

| 실제 질문 | 표시된 5개 선택지 | 선택한 답 | 후보 수 |
| --- | --- | --- | --- |
| 물건에 있던 장식이나 구별되는 특징 중 기억나는 것을 골라 주세요. | 노란 삼각 배지 / 빨간 사각 핀 / 초록 줄무늬 배지 / 파란 원형 핀 / 보라 타원 핀 | 빨간 사각 핀 | 5 → 5 |
| 물건에 적힌 문구 중 기억나는 것을 골라 주세요. | XY / MJ / RT / KL / AB | AB | 5 → 4 |

두 답이 모두 어긋난 `P01`만 제외됐다. `P02`, `P03`은 두 답 모두 일치했고, `P04`, `P05`는 장식 하나만 어긋났다. 네 후보를 더 구분할 질문이 없어 **판정 보류**였다.

### 5. 우산의 공개 특징으로 후보를 하나로 좁힌 경우

입력은 “검은색 우산을 잃어버렸어요.”였다.

| 실제 질문 | 표시된 5개 선택지 | 선택한 답 | 후보 수 |
| --- | --- | --- | --- |
| 기억하는 물건의 재질을 골라 주세요. | leather / vinyl / polyester / canvas / nylon | nylon | 5 → 1 |

`U01`이 남았다. 재질은 공개 특징이고 비공개 확인 근거는 0개였으므로 **판정 보류**였다.

### 6. 우산 질문에서 Gemini가 만든 선택지를 고른 경우

입력은 “우산을 잃어버려서 찾고 있어요.”였다.

| 실제 질문 | 표시된 5개 선택지 | 선택한 답 | 후보 수 |
| --- | --- | --- | --- |
| 기억하는 물건의 재질을 골라 주세요. | polyester / vinyl / leather / canvas / nylon | polyester | 5 → 5 |

`polyester`는 Gemini가 만든 선택지였다. 이 질문의 목적은 공개 특징으로 후보를 좁히는 것이어서, 등록 값에 해당하지 않는 선택은 후보 탈락이나 비공개 오답 횟수에 반영되지 않았다. 결과는 **판정 보류**였다.

### 추가 질문 없이 끝난 네 사례

| 실제 입력 | 확인 내용 |
| --- | --- |
| 흰색 Apple 이어폰을 잃어버렸어요. | 브랜드가 비어 있는 `M01`을 품목·색상으로 찾았다. 확인할 비공개 특징이 없어 `insufficient_evidence`였다. |
| 보온병을 찾고 있어요. | `M03`을 찾았고, 확인할 비공개 특징이 없어 `insufficient_evidence`였다. |
| 검은색 헬멧을 잃어버렸어요. | 합성 헬멧 10개는 모두 보관 조건을 충족하지 않아 `no_candidates`가 반환됐다. |
| 잘 모르겠어요. | 비교할 물품 단서가 없어 `needs_clues`가 반환됐다. |

## 재실행

Gemini 키와 모델이 설정된 상태에서 `backend` 폴더에서 실행한다. 출력 폴더에는 새 경로를 지정한다.

```powershell
python -m app.ai_ownership_verification.experiments.run_ownership_live --suite user-flows --output-dir .pytest_cache/ownership-user-flows-rerun --max-requests 30
```

[실행 원본 JSON](ownership_workflow_user_flows_20261110.json)에는 첫 실행과 재실행을 구분해 저장했다. 각 응답의 선택지 순서, 일치·불일치한 후보 ID, 답변 직후 남은 후보, 실제 Gemini 요청 결과를 확인할 수 있다.
