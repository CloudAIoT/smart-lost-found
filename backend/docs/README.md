파트 간 공통 계약의 원본은 루트 `docs/`에 둔다. 합의한 변경은 해당 원본과 함께 갱신한다.

## 표기

| 표기 | 뜻 |
| --- | --- |
| 구현 | 실제 소스에 있는 동작이다 |
| 실험 구현 | 호출·검증 코드가 있지만 업무 API·DB에 연결되지 않았다 |
| 미구현 | 현재 함수·라우터·테이블에 없다 |
| 미정 | 원문에서 협의 대상으로 두었거나 서로 충돌한다 |

## 사용자 결정

- 습득자 본인인증은 미정으로 두고 관련 DB·API 확정을 보류한다.
- 이미지 분석 성공 후에만 등록용 보관함 개방을 허용한다.
- 완료 버튼 후 백엔드가 문을 조회하고, 사용자 확인과 `closed`를 함께 만족하면 투입·수령 완료로 처리한다.
- 사진 원본은 비공개 S3에, 객체 키·메타데이터는 DB에 저장한다.
- 소유 확인 AI의 입출력·판정 기준·코드 발급 조건은 협의 전까지 미정으로 둔다.
- AI 담당자가 특징 추출·질문 생성·답변 평가를, Pi와 FE는 각각 별도 담당자가 구현한다. BE는 데이터 저장·연동·평가 결과에 따른 반환 처리를 맡는다(D08·D09).
