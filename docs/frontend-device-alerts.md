# 프론트 요청: 장치 경고 표시와 다시 열기 버튼

- 작성: 정형식(라즈베리파이), 2026-11-22
- 대상 화면: 키오스크(촬영 상자 옆 아이패드), 웹 포털
- 근거: [실험 0002](../raspberry-pi/docs/experiments/0002-mqtt-alert-test.md)(11/21 실제 Pi 시험), [기능 명세](../backend/docs/functional-spec.md)의 F12-A 보관 완료, F12-B 수령 완료, 8-1 F14 장치 상태와 경고

## 왜 필요한가

이제 두 Pi가 보낸 경고와 칸 상태가 서버까지 들어오고, 백엔드는 칸 상태와 어긋나는 보관·수령 완료를 409로 막는다(#53). 그런데 지금 키오스크 화면에는 경고를 보여 주는 곳도, 막힌 뒤 칸을 다시 여는 버튼도 없다. 11/21 시험에서는 다시 열기를 Swagger로 대신 불렀다. API와 응답 형식은 기능 명세에 이미 있으니, 아래는 화면에서 해 줄 일만 적었다.

## 요청 1. 다시 열기 버튼 (가장 급함)

| 화면 | 언제 | 보여 줄 문구 | 버튼이 부를 API |
| --- | --- | --- | --- |
| 보관 완료 | '완료'가 409 `ITEM_NOT_DETECTED` | 물건이 감지되지 않았어요. 다시 넣어 주세요. | `POST /api/registrations/{registration_id}/deposit/reopen` |
| 수령 완료 | '수령 완료'가 409 `ITEM_STILL_INSIDE` | n번 보관함에 물건이 남아 있어요. 다시 열어 꺼내 주세요. | `POST /api/pickup/{found_item_id}/reopen` |

- 다시 연 뒤에는 원래 화면('n번 보관함이 열렸습니다')으로 돌아가 완료를 다시 누를 수 있으면 된다.
- 수령 다시 열기는 OTP를 다시 받지 않는다. 반환 코드는 처음 열 때 이미 쓰였다(F12-B).
- 문구는 지금 `ERROR_MESSAGES`에 있는 것을 그대로 써도 된다.

## 요청 2. 경고 표시

- 키오스크 화면: 이 키오스크의 새 경고를 몇 초마다 `GET /api/alerts?kiosk_id={키오스크 ID}&since={마지막으로 본 시각}`으로 가져와 화면 위쪽에 띄운다. `message`는 Pi가 한국어로 보내므로 그대로 쓰면 되고, `locker_number`가 있으면 칸 번호를 같이 보인다.
- 색: `alarm`(빨강)은 FORCED_OPEN, ITEM_MISSING. `warning`(주황)은 TAMPER, ITEM_NOT_DEPOSITED, ITEM_NOT_TAKEN, CAPTURE_ITEM_LEFT.
- 시연에서 꼭 보여 줄 장면: 강제 개방(경보), 물건 사라짐(경보), 촬영 상자에 남음(경고).
- 있으면 좋음: 웹 포털에 장치 상태(`GET /api/kiosks/{kiosk_id}/device-status`)를 보여 주는 작은 표. 두 Pi의 online·offline과 칸별 문·물건 상태다. 빈 배열은 '정상'이 아니라 '상태 모름'이다(8-1).

## 요청 3. 물건 종류 오류 표시 복구

#48에서 확인한 물건 종류 오류 표시(`categoriesError`)가 아직 main에 없다. 새 브랜치에서 PR로 올려 주면 된다.

## 시연 때 확인할 것

- 아이패드 키오스크는 'Swagger 테스트 키오스크'(`00000000-0000-0000-0000-000000000001`)로 고른다. 두 Pi가 이 키오스크 ID로 경고를 보낸다.
- 프론트를 배포한 뒤에는 키오스크 페이지를 새로고침한다. 11/21에는 배포 전에 열어 둔 페이지가 새 안내 대신 일반 오류 문구를 보였다.

## 확인 방법

- 강제 개방: 보관함 Pi에서 `python3 tools/sim.py locker 2 force-open`을 실행하면 화면에 빨간 경보가 떠야 한다. 끝나면 2번 버튼으로 닫는다.
- 다시 열기: 보관함이 열렸을 때 넣지 않고 닫은 뒤 '완료'를 누르면 안내와 다시 열기 버튼이 나와야 한다. 다시 열고 넣은 뒤 닫으면 완료된다. Pi 자동 모드(#59)가 병합되면, 보관 안 됨은 열기 전에 `python3 tools/sim.py locker 1 skip`으로 만든다.
