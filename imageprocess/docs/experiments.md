# Qwen / Gemini 실험 기록

기존에 사용자가 실행해 저장한 결과를 검토한 기록이다. 이 문서 정리 과정에서 실제 추론이나 API 호출을 추가로 수행하지 않았다. **사진 1건의 관찰이며 모델의 일반적인 정확도를 나타내지 않는다. 최종 모델 선택은 보류한다.**

## 비교 대상과 조건

- 입력: 검정 Carhartt 필통 사진 1장, 카테고리 `필통`.
- Qwen: `mlx-community/Qwen2.5-VL-3B-Instruct-4bit`, 로컬 MLX.
- Gemini: 저장된 결과의 모델 ID `gemini-3.6-flash`, API 실행 결과.
- 기준 파일: 로컬 `outputs/legacy/result_with_category.json`, `outputs/gemini.json`.
- Gemini 저장 결과는 2026-11-04 실험 기록이다. Qwen은 이전에 저장한 결과를 활용했다.

원본 사진과 전체 결과는 개인 로컬 자료로 Git에서 제외한다. 아래는 검토에 필요한 관찰과 측정값만 정리한 것이다.

## 관찰 내용

| 항목 | Qwen 결과 | Gemini 결과 | 해석 |
| --- | --- | --- | --- |
| 카테고리 | `pencil_case` | `pencil_case` | 두 결과 모두 입력 힌트를 제공한 조건 |
| 브랜드·문구 | Carhartt / carhartt | Carhartt / carhartt | 두 결과가 일치 |
| 색상 | black | black, white, orange | Gemini는 패치 색상도 포함. 주요 색상 분리 규칙은 필요 |
| 재질 | unknown | fabric | Qwen의 불확실 표현 자체를 오답으로 세지 않음 |
| 부착물 | blue pin with white wings | two metal pins near the top right | Qwen은 별개 핀의 특징을 섞어 표현. Gemini는 두 핀을 구분해 기술 |
| 물품 구조 | 로고·핀 중심 | 로고 패치·상단 손잡이·측면 지퍼 | Gemini가 이 사례의 구조를 더 자세히 기술 |

이 사진에서는 Gemini의 설명이 물품 구조와 부착물 수를 더 잘 반영했다. 다만 핀의 세부 색상·모양을 충분히 기술하지 않은 부분도 있다. 색상을 더 많이 나열하거나 설명이 더 긴 것만으로 품질이 높다고 평가하지 않는다.

초기 Qwen 출력에는 필통을 지갑으로 분류하거나 가죽·은색 지퍼로 잘못 기술한 사례가 있었다. 이후 완성 예시를 제거한 프롬프트, 카테고리 힌트, 엄격한 JSON 검증을 추가했다. 현재 표는 초기 출력이 아닌 카테고리를 제공한 결과를 기준으로 한다.

## 저장된 처리 시간

| 구간 | Qwen | Gemini |
| --- | ---: | ---: |
| 모델/클라이언트 준비 | 3,077.42 ms | 395.38 ms |
| 추론·응답 대기 | 5,486.04 ms | 20,749.36 ms |
| 전체 | 8,665.32 ms | 21,259.90 ms |

이 실행에서 Gemini 추론·응답 대기는 Qwen의 약 3.8배, 전체 시간은 약 2.5배였다. Gemini는 네트워크 왕복·원격 실행을 포함하고, 준비 시간은 SDK 클라이언트 초기화이다. Qwen의 준비 시간은 모델 로딩이므로 같은 작업의 속도로 비교할 수 없다. HTTP 서버에서 모델을 재사용했을 때의 처리량 측정도 아니다.

Gemini 사용량은 입력 1,733토큰, 출력 106토큰, 추론 697토큰, 전체 2,536토큰으로 기록됐다. 토큰 수만 기록하며 요금이나 월 운영 비용은 추정하지 않았다.

## 해석의 한계와 다음 비교 기준

이전 Qwen 파일에는 원본·전처리 이미지·프롬프트의 해시가 없어 두 실행의 조건 일치를 파일만으로 확인할 수 없다. 현재 코드로 새 결과를 저장하면 해시·크기·생성 설정을 함께 기록한다. 기존 결과를 새 코드로 실행한 기록처럼 취급하지 않는다.

현재 기본 설정은 Qwen 최대 512토큰, Gemini 최대 4096토큰이며 Gemini만 API의 JSON Schema 강제를 사용한다. 이전 Qwen 파일에는 생성 설정 기록도 없다. 이 자료는 두 처리 방식의 사례 비교이고 통제된 모델 벤치마크는 아니다.

추가 비교에서는 동일 사진·카테고리로 실행 조건을 기록하고, 기대 특징과 판단 근거를 먼저 작성한다. 여러 카테고리·촬영 각도·조명에서 오분류, 문구 오류, 부착물 오류, 근거 없는 재질 추측, 반복 일관성, 실패율·지연 시간을 평가한다. 카테고리 없이 분석한 결과와 사진 2장 분석 방식도 따로 검토한다. 실제 실행은 사용자가 진행한다.
