# Gemini 단일 사진 10종 실험

실제 저장된 성공 결과에서 특징·시간·검토 의견만 발췌했다. 원본 사진, 개인 경로, 요청 ID, 키, 전체 실행 원문은 포함하지 않았다. [발췌 JSON](single-photo-10-cases.json)을 함께 제공한다.

이 기록은 영어 카테고리·색상을 사용한 `fixed_common_v2` 결과다. 현재 한국어 출력 규격 `fixed_common_v3_ko`로 재추론하거나 기록을 번역한 결과가 아니다.

## 입력과 조건

- 물품마다 사진 1장과 파일명에서 해석한 카테고리만 제공했다. 상세 설명·브랜드·캐릭터 정답은 입력하지 않았다.
- 모델: gemini-3.6-flash. 전처리: 긴 변 최대 1280px. temperature 요청값 0, 출력 예산 8192 tokens.
- 할당량 오류로 나뉜 실행에서 사진별 성공 결과 10개를 모았다. 실패 요청과 재실행 대기 시간은 아래 시간에서 제외한다.
- 두 사진을 함께 분석한 실험이 아니다. 이번 두 사진 입력 구현의 실제 추론 정확도·지연·할당량 사용은 아직 검증하지 않았다.

## null과 공통 필드

category·color·shape·surface_texture·structure는 10장 모두 값이 있었다. brand는 책·우사기 인형·두 번째 지갑 3장에서 null, visible_text는 이어폰 케이스·충전기·첫 번째 인형·지갑 2장 등 5장에서 null이었다. 키 이름은 모든 사례에서 동일했다.

## 해석과 후속 검증

공통 필드 7개와 특이 특징 한 목록은 이 표본에서 다양한 물품을 같은 구조로 담았다. 자율 캐릭터 식별은 우사기 사례에서 유용했지만 주댕치 사례에서 오인식했다. 모델의 확신이나 JSON 형식 검증을 관찰 사실의 검증으로 취급하지 않는다.
소유 확인 문제의 정답에는 관찰 가능한 색·부착물·위치 등을 우선 검토하고 캐릭터명·브랜드·세부 상품 분류는 별도 확인이 필요하다. 이 데이터는 라벨링된 전체 정확도 평가나 모델 간 통제 벤치마크가 아니다.
두 사진 처리에서는 같은 물건의 서로 다른 각도를 촬영하고, 같은 부착물을 중복 집계하지 않는지, 한쪽에만 보이는 정보를 보완하는지, 상충하는 글자·색상·캐릭터 식별을 어떻게 처리하는지 추가 검증해야 한다.
