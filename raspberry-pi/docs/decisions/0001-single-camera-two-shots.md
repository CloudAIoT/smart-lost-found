# 0001. 카메라 1대로 물건 방향을 바꿔 2장 촬영

- 날짜: 2026-10-06
- 상태: 결정 (팀 회의)

## 배경

물건을 정확히 인식하고 판별하려면 한 면이 아니라 두 방향에서 찍은 사진이 필요하다. 처음에는 Camera Module 3 두 대를 촬영 Pi에 연결해 위와 옆을 한 번에 찍으려 했다(#4).

## 문제

- Raspberry Pi 4에는 카메라(CSI) 단자가 1개뿐이다. 보드의 다른 리본 단자(DISPLAY)는 화면 출력용이라 카메라를 연결할 수 없다.
- 한 단자에 카메라 여러 대를 번갈아 연결하는 전환 보드(Arducam Multi Camera Adapter V2.2)는 Camera Module 3(IMX708)를 Raspberry Pi OS Bookworm·Trixie에서 지원하지 않는다.

## 검토한 방법

| 방법 | 판단 |
| --- | --- |
| 촬영 Pi를 카메라 단자가 2개인 Raspberry Pi 5로 교체 | 추가 구매 필요 |
| Pi 4 두 대가 카메라를 하나씩 연결 | 두 Pi가 모두 촬영 상자 옆에 있어야 하고 보관함 제어를 나눠야 함 |
| 한 대는 USB 웹캠으로 대체 | 두 사진의 화질·색감이 달라짐 |
| 카메라 1대로 두 번 촬영 | 추가 장비 없음. 촬영 사이에 사용자가 물건 방향을 바꿔야 함 |

## 결정

카메라 1대로 첫 사진을 찍고, 키오스크 화면에서 물건을 돌리거나 눕혀 달라고 안내한 뒤 두 번째 사진을 찍는다.

## 영향

- 통신 규약: 촬영 명령 한 번에 사진 1장(JPEG). 백엔드는 같은 `registration_id`로 촬영 명령을 두 번 보낸다.
- 키오스크 화면: 두 촬영 사이에 방향을 바꿔 달라는 안내 화면이 필요하다.
- 하드웨어: 한 장에 윗면과 옆면이 함께 보이도록 카메라를 비스듬히 위에서 내려다보게 다는 방안을 실험한다. 물건 위치가 바뀌므로 촬영마다 초점을 다시 맞춘다.
