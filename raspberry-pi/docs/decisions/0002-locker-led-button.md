# 0002. 시제품 보관함은 잠금장치 대신 LED와 버튼으로 보여 준다

- 날짜: 2026-11-15
- 상태: 결정 (팀 협의, 교수님 조언)

## 배경

보관함 Pi는 칸마다 잠금장치와 문 센서를 달아, 백엔드의 개방 명령으로 문을 열고 문 상태를 알려 주도록 설계했다([하드웨어 설계](../../hardware/README.md)). 이대로 만들려면 솔레노이드 잠금장치, 릴레이, 12V 전원, 리드 스위치를 사야 하고, 일부 부품은 3D 프린터로 뽑을 계획이었다.

## 문제

- 3D 프린터를 빌리기 어려웠다. 그래서 상자를 3D 프린터 없이 직접 만들어야 한다.
- 교수님께서 하드웨어를 자세히 구현할 필요는 없고, 무엇을 하려는지 보여 줄 수 있으면 된다고 하셨다. 팀원들과도 같은 방향으로 정했다.

## 검토한 방법

| 방법 | 판단 |
| --- | --- |
| 설계대로 잠금장치와 문 센서를 단다 | 잠금장치와 센서 부품을 따로 사야 한다. 시연에서 보여 줄 것에 비해 준비가 크다 |
| 칸마다 LED만 단다 | 어느 칸이 열렸는지는 보이지만, 문이 닫혔다는 것을 알릴 방법이 없다 |
| 칸마다 LED와 버튼을 단다 | 키트 부품만으로 개방과 닫힘을 모두 보여 줄 수 있다 |

## 결정

- 상자는 3D 프린터 없이 직접 만든다. 재료는 정하는 중이다.
- 칸마다 LED 하나와 버튼 하나를 쓴다. 개방 명령을 받으면 그 칸의 LED가 깜빡여 어느 칸을 열면 되는지 알려 준다.
- 문 센서 대신, 물건을 넣거나 꺼낸 뒤 그 칸의 버튼을 누르면 문이 닫힌 것으로 본다. 백엔드는 보관·수령을 완료하기 전에 문이 닫혔는지 확인하므로([D03·D06](../../../backend/docs/spec-review.md)) 닫힘을 알릴 방법이 필요하다.
- 잠금장치와 문 센서는 향후 과제로 미룬다.

## 영향

- 통신 규약은 바뀌지 않는다. 개방(`POST /lockers/{n}/open`)과 문 상태(`GET /lockers/{n}`)를 LED와 버튼으로 처리한다.
- 핀은 하드웨어 설계의 배정안을 따른다. 잠금장치 자리(GPIO 17, 27)에 LED, 문 센서 자리(GPIO 22, 23)에 버튼을 꽂아, 나중에 실제 부품으로 바꿔도 같은 핀을 쓴다.
- 키트(입출력 키트)의 LED, 저항, 푸시 버튼, 브레드보드로 만들 수 있어 추가 구매가 없다. 설계에서 사야 했던 솔레노이드 잠금장치, 릴레이, 12V 어댑터, 리드 스위치가 필요 없어졌다.
- 카메라 거치대는 3D 프린터 없이 만들 방법을 정해야 한다.
