# 0005. 키오스크 화면은 촬영 Pi 모니터 대신 아이패드로 띄운다

- 날짜: 2026-11-18
- 상태: 결정 (2026-11-18 팀 회의)

## 배경

처음에는 촬영 Pi에 모니터·키보드·마우스를 연결하고, 키오스크 웹 화면을 촬영 Pi의 브라우저로 띄울 계획이었다. 그래서 전원을 켜면 브라우저가 저절로 뜨고, 사용자가 브라우저를 닫거나 주소를 바꾸지 못하게 막는 일(키오스크 화면 자동 실행과 고정)을 Pi 쪽 할 일로 두었다.

그런데 프론트 담당이 웹을 배포해서, 브라우저만 있으면 어느 기기에서나 키오스크 화면을 열 수 있게 되었다.

## 결정

- 촬영 상자 옆에 아이패드를 두고, 배포된 웹의 키오스크 화면을 띄운다.
- 촬영 Pi에는 모니터·키보드·마우스를 연결하지 않고 카메라만 맡긴다.
- 키오스크 화면 자동 실행과 고정은 하지 않는다.

## 영향

- 두 Pi는 촬영과 보관함 제어만 맡는다. 화면은 지금처럼 백엔드하고만 통신하므로 Pi와 백엔드의 통신 구조는 바뀌지 않는다.
- 키오스크 화면은 아이패드에서 손가락으로 누르는 터치 화면이 된다. 키보드·마우스를 전제로 한 설명은 터치 기준으로 본다.
- 하드웨어 설계의 모니터·키보드·마우스 자리는 아이패드로 바뀐다.
